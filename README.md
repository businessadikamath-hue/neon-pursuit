# Neon Pursuit

Offline WebGL2 racing game with Blender-authored vehicle, scenery, wildlife, road, ocean, and cinematic assets.

## Run locally

Open [`outputs/Neon-Pursuit/index.html`](outputs/Neon-Pursuit/index.html), or use `outputs/Neon-Pursuit/Launch.cmd` on Windows.

The editable Blender cinematic is in [`outputs/Neon-Pursuit/gallery/blender/`](outputs/Neon-Pursuit/gallery/blender/). [`outputs/Neon-Pursuit/BLENDER-ALL-OBJECTS.md`](outputs/Neon-Pursuit/BLENDER-ALL-OBJECTS.md) documents the 849-mesh asset library and runtime hero-car replacement. The complete packaged build is [`outputs/Neon-Pursuit.zip`](outputs/Neon-Pursuit.zip).

The garage includes named reference vehicles, including the Koenigsegg Jesko Attack. See [`outputs/Neon-Pursuit/REAL-CAR-SPECS.md`](outputs/Neon-Pursuit/REAL-CAR-SPECS.md) for the sourced specifications and the distinction between real references and arcade tuning.
